# Brag Plan: FlyBrain

## Rubric Answers
- **What is it?** An interactive browser simulation of the Drosophila melanogaster (fruit fly) brain with 139,255 neurons and 2.7M synaptic connections computed in real time.
- **Who is it for?** Computational neuroscientists, bioinformaticians, engineers, and tech enthusiasts.
- **What sets it apart?** The creature is NOT pre-scripted with if/else or canned animations. Decisions emerge biologically from signal propagation through connectome pathways.
- **Strongest claim?** 139,255 neurons + 2.7M connections simulated live in a browser tab using Web Workers & WebGL.
- **Visual hook?** A glowing neural connectome network pulsating in sync with biological sensory reactions (feeding, mechanosensory touch, wind, phototaxis).
- **Tone:** Polished / Cinematic Tech Showcase.
- **Target Duration:** 18 seconds (1920x1080 landscape, 30fps).

## Storyboard
- **Scene 1 (0s - 4s): The Hook**
  - "Can an entire biological brain run inside a browser tab?"
  - Dramatic glowing title, dark futuristic background, pulsing synapse grid.
- **Scene 2 (4s - 9s): The Scale & Science**
  - "139,255 Neurons. 2.7 Million Synaptic Connections."
  - FlyWire Whole-Brain Connectome (Nature 2024).
  - Emergent Leaky Integrate-and-Fire (LIF) network visualization.
- **Scene 3 (9s - 14s): Emergent Behavior**
  - "No scripts. No pre-recorded animations."
  - Real-time sensory inputs: Touch (Mechanosensory), Food (Gustatory), Wind (Johnston's organ).
  - Neural clusters firing live: Sensory → Central → Drives → Motor.
- **Scene 4 (14s - 18s): Outro & CTA**
  - "FlyBrain: Open Source Computational Neuroscience in WebGL."
  - Explore the virtual connectome live.
